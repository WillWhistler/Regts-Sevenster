# The accompanying paper

`rstheorem.pdf` is

> W. Whistler, *Mixed partition functions are exactly the graph
> parameters of exponentially bounded edge-connection rank*,
> [arXiv:2607.27198](https://arxiv.org/abs/2607.27198),

the text whose numbering the formalization's statements and
documentation match. The paper's canonical home is its arXiv
page.

The Main Theorem includes the sharp budget `k + 2ℓ ≤ R`.
Section 4 uses Schrijver's factorial argument for nilpotent traces
and a commutant estimate for the colour bound. Section 7 identifies
the minimum dimension through even connection-rank growth and
characterizes prescribed parity dimensions by padding. Appendix A
proves rational trace zeta functions from rectangular Schur
vanishing, with exponential growth as a sufficient condition.
